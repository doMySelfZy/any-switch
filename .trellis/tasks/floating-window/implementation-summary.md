# 悬浮窗功能实现总结

## 实现日期
2026-09-13 至 2026-09-14

## 功能概述
在 Windows/macOS 桌面上创建一个悬浮窗口，显示所有站点的余额信息，无需打开主窗口即可查看。

## 已实现的功能

### 1. 后端实现 (Rust/Tauri)

#### 新增模块
- **`src-tauri/src/floating_window.rs`**: 悬浮窗管理模块
  - 窗口创建、显示、隐藏
  - 窗口位置管理
  - 自动初始化逻辑

- **`src-tauri/src/commands/floating.rs`**: Tauri 命令
  - `get_all_sites_quota`: 获取所有站点余额汇总
  - `toggle_floating_window`: 切换悬浮窗显示/隐藏
  - `save_floating_window_position`: 保存窗口位置
  - `reset_floating_window_position`: 重置窗口到默认位置（右下角）
  - `set_floating_window_auto_refresh`: 设置自动刷新间隔

#### 数据结构
- **`FloatingWindowSettings`**: 悬浮窗配置
  - `enabled`: 是否启用
  - `auto_refresh_minutes`: 自动刷新间隔（分钟）
  - `position_x`, `position_y`: 窗口位置
  - `width`, `height`: 窗口尺寸
  - `collapsed`: 是否收起（预留字段）

- **`SiteQuotaSummary`**: 站点余额汇总
  - 站点 ID、名称、协议类型
  - 余额信息（剩余、已用、总额、单位）
  - 额度窗口信息
  - 最后更新时间

#### 数据库迁移
- 在 `settings` 表中添加悬浮窗配置字段
- 支持旧数据自动迁移

### 2. 前端实现 (Vue 3 + TypeScript)

#### 新增页面
- **`src/pages/FloatingWindow.tsx`**: 悬浮窗主页面
  - 站点余额列表显示
  - 自动刷新逻辑
  - 拖动窗口位置保存
  - 加载状态与错误处理

#### UI 设计
- **展开状态**:
  - 标题栏：「站点余额」+ 最后更新时间
  - 列表区域：站点名称、余额、使用情况
  - 操作按钮：刷新、设置、关闭
- **视觉风格**:
  - 深色主题（毛玻璃效果）
  - 圆角边框（16px）
  - 半透明背景
  - 流畅的加载动画

#### 交互特性
- 点击站点卡片可查看详细信息
- 鼠标悬停显示额外信息（到期时间、额度窗口）
- 拖动窗口自动保存位置
- 支持键盘快捷键（ESC 关闭）

### 3. 设置页面集成

在 `src/pages/SettingsPage.tsx` 中添加：
- 悬浮窗开关
- 自动刷新间隔设置（1-60 分钟）
- 重置窗口位置按钮

### 4. 窗口特性

#### Tauri 窗口配置
- 无边框窗口（frameless）
- 始终置顶（always-on-top）
- 可拖动区域（data-tauri-drag-region）
- 固定尺寸：300x500px
- 默认位置：屏幕右下角（距边缘 20px/60px）

#### 跨平台支持
- ✅ Windows
- ✅ macOS
- ⚠️ Linux（理论支持，未测试）

### 5. 自动化行为

#### 启动时
- 如果设置中启用了悬浮窗，自动显示
- 自动拉取所有站点的余额信息
- 恢复上次保存的窗口位置

#### 运行时
- 根据设置的间隔自动刷新余额（默认 5 分钟）
- 窗口位置变化时自动保存到数据库
- 关闭悬浮窗时更新设置状态
