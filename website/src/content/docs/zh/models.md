模型列表挂在站点上，不是全局一份。换站点就会换列表。

## 拉取

在站点详情点击「拉取模型」，应用会请求该站点的模型接口并写入本地列表。只影响 AnySwitch 里的列表，不会自动改 Claude Code / Codex / Pi，直到你在应用中心点应用。

## 手动添加

上游列表不全或不提供列表时，用「手动添加」写入 model id。id 必须与上游实际接受的字符串一致。

## 测试

「测试」会对选中的模型发探测请求，可串行或并行。没有可用 API Key 时无法测试。结果只表示当前线路此刻能否响应，不是永久保证。

## 清理

可清空整个列表或删除选中项。这只改本地列表，可以再次拉取。

## 主模型

站点上的「主模型」会作为应用中心的默认选择。Claude Code、Codex 与 Pi 仍要在各自表单里确认后再写入。
