一个站点可以有多条 Base URL。第一项是当前 / 默认线路。

## 测速

在线路下拉中可测速。设置里可配置测速结果有效期（默认 10 分钟）；超时后再次打开下拉会自动重测。

## 切换时会发生什么

切换确认框会说明：默认会把 **已经应用到 Claude Code / Codex / Pi 的 API 地址** 改成这条线路。也可以选择「跳过应用」，只改站点当前线路，不动目标 CLI。

可能的结果：

- 已切换线路并同步应用地址
- 线路已切换，部分应用同步失败
- 已切换线路（站点 only）
- 已切换线路，未同步已应用的工具
